# Generating XML files from Fabricate

This example shows how to generate XML files from Fabricate.

## Prerequisites

- Node.js v20 or later
- A Fabricate API key
- An Ephemeral API key

## Setup

Install dependencies

```bash
yarn install
```

Copy .env.example to .env and adjust the values accordingly.

```bash
cp .env.example .env
```

## Running the example

```bash
yarn start
```

## Output

The example will generate XML files in the `data` directory.
